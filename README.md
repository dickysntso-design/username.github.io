# Portofolio Dicky Santoso

Repository ini berisi portofolio pribadi Dicky Santoso yang menampilkan profil profesional, pengalaman kerja, keahlian, pencapaian, pendidikan, serta kontak untuk keperluan rekrutmen. Situs ini ditujukan untuk mendukung lamaran kerja pada posisi Admin Staff, Data Entry, Warehouse Staff, Logistics Staff, dan posisi operasional administrasi lainnya.

## Deskripsi Proyek

Portofolio ini dibuat sebagai halaman web sederhana, responsif, dan profesional untuk memperkenalkan latar belakang kerja Dicky Santoso kepada perekrut. Seluruh struktur halaman dirancang agar mudah dibaca, cepat dipahami, dan siap dipublikasikan melalui GitHub Pages [web:86][web:81][web:91].

## Fitur

- Tampilan responsif untuk perangkat desktop dan mobile.
- Ringkasan profil profesional.
- Daftar pengalaman kerja.
- Daftar keahlian utama.
- Bagian achievement dan pendidikan.
- Tombol kontak WhatsApp dan email.
- Tombol unduh CV.
